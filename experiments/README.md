# ChatGPT sub-2 stress experiment for Salvador v0.0.4

This folder was regenerated by OpenAI ChatGPT on 2026-06-21 for the v0.0.4 manuscript revision.
The purpose is to test whether the observed behavior of `salvador.algorithm.find_vertex_cover`
is more consistent with a constant `(2 - epsilon)` phenomenon than with a `sqrt(2)` phenomenon.

The experiment is deliberately small and reproducible.  It does not use MILP.  Exact optimum
vertex-cover sizes are computed through the identity `tau(G) = |V| - alpha(G)` using a deterministic
branch-and-bound Maximum Independent Set solver.

Reproduce from the repository root:

```bash
python experiments/chatgpt_sub2_experiment.py
```

Generated outputs:

- `chatgpt_sub2_experiment.json`: complete parameters, environment, witnesses, summaries, and raw rows.
- `chatgpt_sub2_summary.csv`: compact family-level table for the paper.

Interpretation: the exhaustive search up to 6 vertices produces a ratio `3/2 > sqrt(2)`, so the
experiment rejects a universal `sqrt(2)`-type interpretation for this implementation.  However, a deterministic ChatGPT-guided stress witness attains ratio `5/3`, and all generated/sample instances remain below `7/4 = 2 - 1/4`, so the run is compatible with a weaker constant sub-2 conjecture.  This is empirical evidence only, not a proof.
